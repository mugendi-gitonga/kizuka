## Tips for Best Results

1. **Specificity**: Include dark theme, cyan/electric blue colors, and fintech aesthetic in prompts
2. **Size Ratios**: Mention aspect ratios (16:10, 4:3, square)
3. **Style Keywords**: Use "isometric 3D", "minimalist", "fintech", "professional"
4. **Color Palette**: Always mention: dark navy, electric cyan, purple accents
5. **Resolution**: Ask for "high resolution", "professional quality", "4K suitable"
6. **Multiple Variations**: Generate 3-5 variations and choose the best

## Image Placement in HTML

Once you've generated images, save them as:
- `landing/static/images/hero-dashboard.png`
- `landing/static/images/africa-map.svg` (or PNG)
- `landing/static/images/security-vault.png`
- `landing/static/images/step-1-api.png`
- `landing/static/images/step-2-payment.png`
- `landing/static/images/step-3-settlement.png`
- `landing/static/images/partner-logo-1.svg`
- `landing/static/images/mobile-money-flow.png`

Then update the HTML placeholder `<div>` tags with actual `<img>` tags.
